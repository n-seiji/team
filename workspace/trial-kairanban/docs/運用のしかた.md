# 回覧板アプリ 運用のしかた（班長・役員向け）

## 1. どこで動かすか
- 町内会で **小さなパソコン（Raspberry Pi など、手のひら大）を1台買い**、**会長宅（または集会所）** のネットにつなぎ、電源を入れておきます。
- 外のスマホからは、**無料の「つなぎ役」（Cloudflare）** と **町内会名義のインターネットの住所（ドメイン。例: kairan-○○町.jp）** を通して開きます。名簿や読んだ記録は、この機械の中だけにあり、外の会社には預けません。

## 2. 費用（月々の支払いはありません）
| いつ | 内容 | 金額（目安） |
|---|---|---|
| 最初に1回 | 機械・電源・ケース・USBメモリ | 約15,000円 **（総会で確認）** |
| 毎年 | 電気代（5ワット）約1,400円 ＋ ドメインの更新 約2,000円 | **約3,500円** |

## 3. 必ず守ること
- つなぎ役とドメインの登録は、**個人名ではなく町内会のメールアドレス**で行います。
- **ドメインは毎年4月（総会の月）に、会計係が更新します。** 更新を忘れると、**配ったQRの紙が全部使えなくなります。**

## 4. 管理キー（班長画面の合言葉）を変える
1. 機械係が機械で `node src/tool.ts key /home/kairan/kairanban.env` を実行し、出てきた新しいキーを控えます。
2. そのキーを、この紙の下の欄に書き写します（例: ab3d-k7mn-p2qr）。
3. 機械係が `sudo systemctl restart kairanban` で、機械を新しいキーに切り替えます。
4. 班長は自分のスマホで班長画面を開き、新しいキーを入れます。
- **キーを変えると、古いキーのスマホでは入れなくなります。** 新しいキーを入れ直してください。

## 5. 次の班長への渡し方
1. 上の「4」でキーを新しくします。
2. 封筒に入れて手渡しします：①この紙（新しいキーを書いたもの） ②町内会のメールアドレスとパスワード ③つなぎ役（Cloudflare）とドメインの登録の控え（どちらも町内会のメールで作ったもの）
3. 次の班長がスマホで班長画面を開き、キーを入れて一覧が出るのを、その場で一緒に確かめます。

## 6. 止まったとき・データが消えたとき
- 止まったら：置いている家の人が、電源を抜いて10秒後に差し直します（停電のあとは自動で戻ります）。
- 戻らない・データが消えたら：機械係が、毎晩取る USB メモリの控えから前の日に戻します。
- その間は、紙の回覧板で回します。班長は、その間に読んだ世帯を「紙で読んだ」で記録します。

## 7. 機械係がいないとき・次の機械係への引き継ぎ
- 機械係がいないときは、下の欄の **「代わりの人」** が、4・6 の機械係の仕事をします。
1. 次の機械係を決め、下の欄の「機械係」と「代わりの人」を書き直します。
2. 渡すもの：①機械の置き場所（置いている家の人の名前と電話） ②管理キー（この紙） ③町内会のメールアドレスとパスワード ④控えの入った USB メモリ（機械に差してある場所を見せます）
3. 二人で機械の前に行き、次の機械係が「4」の手順でキーを新しくします。
4. 班長のスマホで班長画面が開くことを、その場で一緒に確かめます。
