# はじめに：請求書を作るまで（約5分）

このツールは、黒い画面（ターミナル）で質問に答えるだけで請求書を作ります。コマンドは最初の `invoice init` 以外、基本的に質問されたことに答えるだけです。打ち間違えても、何も壊れません。

## 1. Node.js を入れる（最初の1回だけ）

1. ブラウザで https://nodejs.org/ja を開きます。
2. 「LTS」と書かれた緑のボタンでダウンロードし、開いて、「次へ」を押していけば入ります。
3. 入ったか確かめます。次の手順でターミナルを開き、これを貼って Enter を押します。

```
node -v
```

`v22.` 以上の数字（例: `v22.18.0`）が出れば成功です。それより小さい数字なら、手順1からやり直して新しい版を入れてください。

## 2. ターミナルを開く

- **Mac**: `command` + `スペース` を押し、「ターミナル」と入力して Enter。
- **Windows**: スタートボタンを押し、「PowerShell」と入力して Enter。

白や黒の画面が開けば OK です。以降のコマンドは、コピーして貼り付け、Enter を押します。

## 3. このフォルダに移動する

このツールのフォルダ（`workspace`）をデスクトップに置いた場合：

```
cd ~/Desktop/workspace
```

（Windows の PowerShell では `cd $HOME\Desktop\workspace`）

## 4. 最初の設定（1回だけ）

```
node src/main.ts init
```

2つ聞かれます。

1. 「あなたの名前（屋号でも可）は？」 → 請求書に載せる名前を入力して Enter
2. 「インボイス登録番号は？」 → `T` から始まる14文字を入力。ない場合はそのまま Enter

## 5. 取引先を登録する（相手ごとに1回）

```
node src/main.ts client add
```

1. 取引先の名前 → 例: `山田商店`
2. 敬称 → 会社なら Enter（御中）、個人なら `様`
3. 源泉徴収するか → 報酬から源泉を引く相手なら `y`、そうでなければ Enter

## 6. 請求書を作る

```
node src/main.ts new
```

1. 取引先を番号で選ぶ（例: `1`）
2. 何月分か → Enter で今月
3. 明細を1行ずつ：名称 → 金額 → （源泉の相手なら）源泉の対象か。終わるときは名称を空にして Enter
4. **確認画面**が出ます。宛名・対象月・合計・源泉を見て、よければ `y`。`y` 以外（Enter も）なら何も保存されず、請求番号も進みません。

`y` を押すと、今いるフォルダに `INV-0001.md` ができます。ブラウザで開いて印刷したい場合は、手順6のコマンドを `node src/main.ts new --format html` にします（`INV-0001.html` ができます）。

## 7. 印刷する（A4）

`INV-0001.html` をダブルクリックしてブラウザで開き、印刷（`Ctrl + P` / `command + P`）を押します。用紙は A4、明細15行までなら1ページに収まります。見本は `sample/見本-山田さんの例.html` です。

## 困ったとき

- 「先に発行者を設定してください」→ 手順4をやってください。
- 「まだ登録されていません」→ 手順5をやってください。
- 途中でやめたいとき → `Ctrl + C`。何も保存されません。
- 発行済みの一覧 → `node src/main.ts list`
